Codie Music Player 使用指南

在 codie 设备上播放网易云音乐 / QQ 音乐 / Bilibili / Spotify(曲库) 的音乐。 本播放器基于 mygo-music（AGPL-3.0）构建。

一、安装

平台 文件 安装方式
macOS codie-music-player-0.1.25.dmg 打开 dmg，把 App 拖进 Applications
Windows codie-music-player-setup-0.1.25-amd64.exe 双击运行安装器
Debian / Ubuntu codie-music-player_0.1.25_amd64.deb sudo dpkg -i <文件> 或双击安装
Fedora / RHEL codie-music-player-0.1.25-1.x86_64.rpm sudo rpm -i <文件>
其他 Linux codie-music-player-0.1.25-linux-amd64.tar.gz 解压后运行 install.sh

四个音源插件（网易云 / QQ / Bilibili / MyGotify）已内置，首次启动自动安装，无需手动添加。

二、首次启动向导

第一次打开应用会自动弹出设置向导，共四步：

第 1 步 · 绑定 codie 设备

  1. 在设备设置页查看设备的 IP 地址（例如 192.168.1.160）
  2. 向导里输入 IP 即可（端口默认 8081，自动补全；也可以写完整 IP:端口）
  3. 点「开始配对」→ 设备屏幕会显示 6 位配对码
  4. 把 6 位码填进向导，点「确认配对」

配对成功后应用会获得独立的客户端凭据，不影响其他已配对的客户端。

第 2 步 · 登录音源

每个音源点「登录」按钮：

  • 网易云 / QQ / Bilibili：弹出二维码，用各自 App 扫码确认
  • MyGotify（Spotify 曲库）：免登录即可搜索播放；要同步自己的歌单/收藏再按插件设置里的说明配置

不登录也能直接搜索播放（公开曲库），登录后解锁会员曲库和个人歌单。

第 3 步 · 尝试播放

点「播放测试曲」，应用会自动完成：搜索 → 取流 → 下载 → 上传到设备 TF 卡 → 设备播放。 声音应该从 codie 设备的喇叭出来。

第 4 步 · 完成

点「开始使用」即完成设置。以后随时可在 设置 → Codie 里： 查看设备状态 / 测试连接 / 忘记设备 / 重新运行向导。

三、日常使用

  • 搜索：左侧选音源，顶部搜索框输入歌名或歌手，点结果旁的 ▶ 直接播放到 codie
  • 歌单 / 专辑 / 歌手页：登录后左侧会出现你的歌单、喜欢的音乐、每日推荐等（取决于音源支持）
  • 播放控制：底部播放条可暂停/上下曲/拖进度/调音量，操作会同步到设备
  • 歌词：正在播放页显示逐字歌词（音源支持时）

四、codie 播放的前提条件

播放到设备需要同时满足：

  1. 设备插着 TF 卡（歌曲会临时上传到卡的 code27/music/ 目录）
  2. 设备上打开了音乐页面（音乐 App 前台运行；应用无法远程打开它）
  3. 设备与应用在同一局域网

满足以上条件时，音源会自动切到 TF 卡通道；播放时进度条实时跟随设备。

五、常见问题

点播放没声音？ 按顺序检查：① 设备音乐页面是否打开；② TF 卡是否插入（设置 → Codie → 测试，应显示"在线 · TF 卡就绪"）；③ 设备音量；④ 某些歌曲需要登录/会员，换个歌试试。

设置里显示"离线"？ 设备与应用不在同一网段，或设备 IP 变了（重启后可能换 IP）。到设备设置页确认新 IP，在 设置 → Codie 重新配对。

网易云提示需要登录 / 只能试听？ 版权或会员限制，扫码登录自己的账号即可。

Spotify 怎么是"MyGotify"？ 它把 Spotify 的曲库/歌单经 YouTube Music 出流（免登录、可推 codie）。官方 Spotify 客户端直连型插件是 remote 播放（在电脑本机出声），无法推到 codie。

想换设备 / 多台设备？ 设置 → Codie → 忘记设备，然后重新配对新设备即可（当前版本同一时间播一台）。
